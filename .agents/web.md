# Web (`apps/web`, `@stockpile/web`)

Vite + React 19 SPA, the web twin of the mobile app. TanStack Router (file-based) + TanStack Query, Tailwind v4,
Privy (`@privy-io/react-auth`, email OTP + embedded Solana wallet). Deployed by `infra/web.ts` to `app.<host>`.

## Hard rules

- Do NOT start dev servers (`bun dev`, `vite`). The user runs them (SST starts it on :5173 in `sst dev`).
- Route names mirror the mobile Expo Router tree: `/`, `/bags`, `/saved`, `/portfolio`, `/account`, `/bag/$id`,
  `/asset/$symbol?bag=`, `/buy/$bagId{,/review,/progress}`, `/sell/$bagId{…}`, `/sell-tokens?mints=`. Keep them in step.
- `src/routeTree.gen.ts` is generated by the router plugin on build/dev. Don't hand-edit it; commit it (typecheck needs it).

## Layout

```
src/routes/            File routes (__root.tsx = app shell + sheets)
src/components/ui/     Primitives: T (type scale), buttons, layout (Page, Card, Collapsible…), theme helpers
src/components/stockpile/  Bag art/cards, story reel, market lines, charts, token avatars
src/components/sheets/ Sign-in, fund, bag preview (bottom sheet on phones, dialog on desktop)
src/components/trade/  Buy / sell / token-sell flow state + UI (review, slide-to-confirm, progress)
src/lib, services/api, hooks, utils   Ported verbatim from apps/mobile/src (platform-free logic)
src/lib/privy/         Privy provider bridge (identity token → API, sign + submit via API) and login form
src/styles.css         Design tokens mirrored from apps/mobile/src/config/theme.ts (light + dark)
```

## Conventions

- Visuals follow the mobile design system: tokens as Tailwind colours (`bg-canvas`, `text-ink-2`, `bg-accent-soft`…),
  type scale utilities (`t-title1`, `t-footnote`…), Ionicons via `react-icons/io5`.
- Shared logic in `src/lib`, `src/services/api`, `src/hooks` is copied from mobile; when fixing logic there, fix both.
- API access only through `src/services/api/*` (SDK + `privy-id-token` interceptor). Never fetch the API directly.
- Large screens: left sidebar tabs; feed is a snapping reel with a story context panel. Small screens: floating tab bar.
- Typecheck: `bun run --cwd apps/web typecheck`; build: `bun run --cwd apps/web build`.
